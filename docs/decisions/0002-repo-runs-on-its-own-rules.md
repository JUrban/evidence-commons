# 0002 — The repository runs on the proposal's own rules

**Date:** 2026-09-26. **Status:** accepted.

**Decision.** PRs are change requests (with revision-record lines). Issues are claims (with resolution protocols) and challenges (with tests). CI is the resolution service for anything checkable — builds, cross-references, schema validation, simulation re-runs. Git commit trailers are the flight recorder for AI-assisted work. Credit is computed quarterly from merged change requests and sustained challenges.

**Why.** The process is the first test of the proposal. If the proposal's own development cannot run on its rules, it should say so before asking a field to.
