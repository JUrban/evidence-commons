# Pilots

- `pilot-A-truth-market.md`, `pilot-B-flight-recorder.md`, `pilot-C-retroactive-round.md` — the pre-registration documents (Section 42 of the master), with hypotheses, design, analysis and stop rules fixed before data exist.
- `runbook-phase3.md` — how to run the first small test with a friendly community, at one-tenth of Pilot A's scale, using the tools in this repository and a play-money market venue.
- `manifold-howto.md` — using an existing open-source play-money prediction-market platform as the market venue before building one.

Each pilot is also registered as a claim in `records/claims/` (EC-001, EC-006, and the retroactive-round claims to follow) so that the pilots trade on their own markets.
